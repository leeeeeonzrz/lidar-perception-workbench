# 架构与算法

## 几何与未知区域

输入为米制、重力对齐、z-up 点云。RANSAC 约束法向，避免把近乎竖直的大平面当成地面，但仍可能误选屋顶。DBSCAN 参数依赖点密度，不是跨距离通用最优值。

栅格统计点数、均值、标准差与极差。未知或点数不足的格子默认为不合格；圆形腐蚀要求完整足迹有观测支持：

$$
F\ominus B=\{x\mid x+B\subseteq F\}
$$

体素和格子尺度越大，细小障碍越容易丢失；越小则资源与稀疏问题更突出。半径等参数不对应实际载体规格。

## 进程与界面

三个工作子进程之外仍有主进程，ROS 部署还有独立驱动。Queue 会序列化，不宣称零拷贝。过载优先保留较新任务，允许丢帧。结果按 sequence 配对并有过期上限；单个 pipeline 对应一个会话，重启应新建实例并清空缓存。

GUI 回调不等待另一算法完成。停止先发事件、等待，再终止超时进程。当前没有自动重启监督器。

## 局部配准

GICP 利用局部表面协方差加权。调用者提供预测位姿；IMU 辅助仅提供旋转增量。质量不足时保留预测，不把失败帧加入地图。fitness 和 RMSE 不是位置真值误差。
