# 公开内容与脱敏范围

公开内容仅包括重新组织的通用算法、数据模型、接口适配、合成样例与说明文档。

| 类别 | 处理 |
|---|---|
| 单位、人员、内部标识 | 从代码、注释、路径与文档移除 |
| 设备地址、账号、序列号、绝对路径 | 改为参数、占位模板或回环演示 |
| 真实图像、点云、地图、录音与标定 | 不分发 |
| 权重、二进制、构建和打包产物 | 不分发 |
| 供应商驱动、SDK 源码、报告与参考材料 | 不复制，仅列外部依赖 |
| 实际验收与性能数字 | 不移植为展示版指标 |
| 原提交历史 | 不导入，使用独立新历史 |

合成数据用于验证结构或数学关系，不代表实际场景表现。真实设备接入需另行提供可用协议、时间与坐标约定、配置及依赖环境。
