# 脱敏与版本边界

此版本采用“原文件保留 + 必要脱敏”的整理方式。当前导入 64 个原材料文件，其中源码（C/C++/Python/头文件）23 个，公开副本约 20,676 行源码，包含注释与空行。该统计包括已有集成组件及历史版本，不代表个人原创工作量。

对比选入文件的原始源码行，20,661 / 20,696 行保持文本相同（99.83%）；新增说明文档不计入此比例。此比例只衡量选入源码的修改幅度，不代表整个材料文件夹的收录比例。逐文件索引见 [SOURCE_INDEX.md](SOURCE_INDEX.md)。

## 本次调整

- 保留原 C++ 驱动、17 个 Python 文件、Qt 界面、多进程流程、launch、服务、消息与实验版本。
- 个人数据目录替换为相对目录；启动脚本根据自身位置寻找工作空间。
- 单播设备地址替换为文档地址。驱动的通用协议常量、端口与算法参数不作机械替换。
- 删除实际 LiDAR/IMU 标定矩阵；原变换计算仍在，运行时必须提供本地 ROS 参数。
- 不上传实测点云、传感器记录、录制文件、打包产物、缓存与构建输出。
- 保留驱动原许可证与来源信息，并明确实时主线和离线实验的版本边界。
- 在原录制 launch 中补上缺失的 `</node>` 闭合标签；原时间戳表达式仍需在实际 ROS 环境中核实。
